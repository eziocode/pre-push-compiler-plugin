Pre-Push Compilation Checker

An IntelliJ IDEA plugin that compiles your changes before git push and blocks the push when there are compilation errors, so broken code never reaches the remote.

Counts come only from users who chose Share when the plugin asked. The plugin sends a random install id, plugin and IDE version, and four numbers — never code, file names, project names or repository details. You can turn it off any time in the plugin's settings under Usage statistics.

Totals refresh live when available; otherwise they come from a snapshot updated every 6 hours.
